OME-Zarr fiji:// link demo

Test page for ome-zarr-fiji-java#102 (issue #68). Requires Fiji-Latest, which ships fiji-links and scijava-desktop, plus the ome-zarr-fiji-ui jar from that PR. Register the scheme once via Fiji → Edit → Options → Desktop…

  • A plain HTTP link to the dataset, for contrast — the browser downloads or shows it:
    https://…/BR00109990_C2.zarr/0
  • A remote OME-Zarr, opened in Fiji:
    fiji://open/url?p=https://…/BR00109990_C2.zarr/0
  • A local OME-Zarr on disk. The path below is an example and will only resolve on the machine that has it — edit it to one of yours:
    fiji://open/file?p=/Users/hahmann/Data/omev5/BR00109990_C2.zarr/0
  • The same local file, but through the open/url from route from fiji links as a file: URL:
    fiji://open/url?p=file:/Users/hahmann/Data/omev5/BR00109990_C2.zarr/0
  • Fiji auto-detecting the source type:
    fiji://open/source?p=https://…/BR00109990_C2.zarr/0
  • Not currently an s3:// target through open/url, kept here to demonstrate the upstream limitation. It is silently caught upstream by Fiji.
    fiji://open/url?p=s3://janelia-cosem-datasets/…/em/fibsem-uint8

Opening honors the configured behavior under Plugins → OME-Zarr → Settings → Opening Behavior Settings (ImageJ, BigDataViewer, or the selection dialog).
